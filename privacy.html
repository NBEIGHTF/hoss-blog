Privacy policy

Last updated November 5, 2026.

Hoss is a personal project. Its app is used by one person, its owner, and is not offered to the public.

What Hoss accesses

Hoss uses the YouTube Data API only to upload and manage videos on its own channel, @hoss-sh. It does not read, collect or store data about viewers or any other YouTube account.

How access is stored

The sign-in token for the channel is kept in the owner's password manager and is never shared or sold. Hoss does not use Google user data for advertising.

This website

This site uses no cookies, analytics or tracking. It is hosted on GitHub Pages, which keeps its own server logs under GitHub's privacy statement.

Removing access

The channel owner can revoke Hoss's access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
